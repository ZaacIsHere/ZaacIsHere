Operator (Zaac) granted standing approval on 2026-07-07 for promoting
hardened principles into .claude/skills/.

Procedure for the curation routine and interactive sessions:
- A principle qualifies for promotion when it is supported by at least two
  independent observations (outcome notes, or repeated across sessions).
- Promote as .claude/skills/<slug>/SKILL.md with frontmatter (name,
  description with clear trigger conditions) and a short procedure body.
- Cite the source principle note and evidence in the skill body.
- Commit skills changes SEPARATELY from memory/ changes, message
  "skills: promote <name>", so each promotion is reviewable and revertable.
- One skill per principle; update the existing skill rather than forking.
- First promotion: delta-check (2026-07-07).
